## 四、库 API 速查（易错点已标注）

### si2c.h（软件 I2C）
```c
typedef struct {
    GPIO_TypeDef *SCL_GPIOx;  uint16_t SCL_GPIO_Pin;
    GPIO_TypeDef *SDA_GPIOx;  uint16_t SDA_GPIO_Pin;
} SI2C_TypeDef;

void My_SI2C_Init(SI2C_TypeDef *SI2C);                                  /* 1 参 */
int  My_SI2C_SendBytes(SI2C_TypeDef*, uint8_t Addr, const uint8_t*, uint16_t);   /* 4 参 */
int  My_SI2C_ReceiveBytes(SI2C_TypeDef*, uint8_t Addr, uint8_t*, uint16_t);
```
内部 `GPIO_Mode_Out_OD` → **必须有上拉电阻**（外部或模块自带）。

### i2c.h（硬件 I2C）
```c
int My_I2C_SendBytes(I2C_TypeDef *I2Cx, uint8_t Addr, const uint8_t*, uint16_t);
int My_I2C_ReceiveBytes(I2C_TypeDef *I2Cx, uint8_t Addr, uint8_t*, uint16_t);
```
第一个参数是 `I2C1`（不是结构体）。

### oled.h
```c
#define OLED_SLAVE_ADDR 0x78
int  OLED_Init(OLED_TypeDef*, OLED_InitTypeDef*);     /* InitTypeDef 只有 i2c_write_cb 一个成员 */
void OLED_Clear/SendBuffer/StartSendBuffer/EndSendBuffer
void OLED_SetCursor(OLED*, int16_t X, int16_t Y)
void OLED_SetPen   (OLED*, uint8_t Pen_Color, uint8_t Width)   /* 3 参！ */
void OLED_SetBrush (OLED*, uint8_t Brush_Color)                /* 2 参！没有宽度 */
void OLED_SetFont  (OLED*, const Font_TypeDef*)
void OLED_DrawString(OLED*, const char *Str)     /* 支持 UTF-8 中文 */
void OLED_Printf(OLED*, const char *Format, ...)
void OLED_StartTextRegion(OLED*, int16_t X, int16_t Y, uint16_t W, uint16_t H)
```
**颜色宏命名不对称**（极易错）：
- 画笔：`PEN_COLOR_WHITE` / `PEN_COLOR_BLACK` / `PEN_COLOR_TRANSPARENT`
- 画刷：`BRUSH_WHITE` / `BRUSH_BLACK` / `BRUSH_TRANSPARENT`（**没有 COLOR**）

### button.h
```c
Button_InitTypeDef: GPIOx, GPIO_Pin,
  button_pressed_cb(void) / button_released_cb(void)
  button_clicked_cb(uint8_t clicks) / button_long_pressed_cb(uint8_t ticks)
  LongPressTime, LongPressTickInterval, ClickInterval
void My_Button_Init(Button_TypeDef*, Button_InitTypeDef*);
void My_Button_Proc(Button_TypeDef*);      /* 主循环里反复调用 */
```
⚠️ 时间参数不设会全为 0 → 「按下即长按」。建议 `LongPressTime=1000, ClickInterval=300, LongPressTickInterval=200`。

## 五、已掌握的知识点

- GPIO：推挽/开漏/上拉输入/AF 复用；`GPIO_WriteBit` 只写 ODR，**能不能驱动引脚取决于模式**
- 时钟门控：`RCC_APB2PeriphClockCmd`（GPIO/AFIO/USART1/SPI1）vs `RCC_APB1PeriphClockCmd`（I2C1/USART2/TIM2~7）
- AFIO 重映射：`GPIO_PinRemapConfig`，必须先开 AFIO 时钟
- USART：115200-8-N-1，`TXE`/`TC` 的区别，printf 重定向靠 `fputc`
- 硬件 I2C：状态机 SB→ADDR→TXE→BTF→AF，开漏 `AF_OD`
- 软件 I2C：START/STOP 时序定义（SCL 高电平期间 SDA 跳变）、第 9 时钟应答
- SPI：W25Q64 命令集（0x06 写使能 / 0x05 读状态 / 0x20 扇区擦 / 0x02 页编程 / 0x03 读 / 0x9F 读ID）
- TIM PWM：72MHz/(PSC+1)/(ARR+1)，20kHz 取 ARR=3599；软启动斜坡
- 数据类型 `uint32_t` 的意义、位操作（`|=` `&=` `^=`）
- 按键三态状态机（短按/长按/双击）、**松手才执行**的实现
- 时间片轮询架构（`GetTick()` 差值判断，全程无 `Delay`）
- 蓝丸板引脚数法（USB 朝上，左/右各 20 脚）

**蓝丸板引脚数法**
- 左排：1=3V3 2=GND 3=5V 4=PB9 5=PB8 6=PB7 7=PB6 8=PB5 9=PB4 10=PB3 11=PA15 12=PA12 13=PA11 14=PA10 15=PA9 16=PA8 17=PB15 18=PB14 19=PB13 20=PB12
- 右排：1=GND 2=GND 3=3V3 4=PB0 5=PB1 6=PB10 7=PB11 8=RST 9=PA0 10=PA1 11=PA2 12=PA3 13=PA4 14=PA5 15=PA6 16=PA7 17=PC13 18=PC14 19=PC15 20=VB

**常用外设默认引脚**

| 外设 | 默认引脚 | 重映射后 |
|---|---|---|
| USART1 | PA9(TX)/PA10(RX) | **PB6/PB7** |
| I2C1 | **PB6(SCL)/PB7(SDA)** | PB8/PB9 |
| SPI1 | PA5(SCK)/PA6(MISO)/PA7(MOSI) | **PB3/PB4/PB5** |
| 板载 LED | **PC13（低电平点亮，3mA/2MHz）** | — |

## 六、踩过的坑（血泪清单，别再犯）

### 1. 库文件被覆盖（发生过 3 次！）
- `my_lib\usart.c` 被粘成了 main 代码 → 恢复
- `my_lib\si2c.c` 被粘成 main 代码（6085→999 字节），又被粘成 `i2c.c` 副本（→4365 字节）→ 最后从原始包恢复
- **教训：只双击 `user\main.c`，粘贴前看标签页文件名**

### 2. 中文乱码
- `my_lib` 下所有文件是 **UTF-8 无 BOM**，Keil 默认按 **ANSI(GBK)** 打开 → 乱码
- **解决**：`Edit → Configuration → Editor → Encoding: Encode in UTF-8 without signature`，改完关掉所有标签重开

### 3. 开漏输出必须有上拉电阻
- `GPIO_Mode_Out_OD` / `_AF_OD` 写 1 只是**放手**，不会输出高电平
- 没上拉 → 线永远上不去 → 从机完全无响应
- OLED 4 针模块一般自带 4.7k；没有的话要补（内部上拉约 40k 太弱，需降速到 ~50kHz）

### 4. 端口写错会静默失败
```c
RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOA, ENABLE);
GPIO_Init(GPIOB, &s);                            /* 时钟没开 → 配置无效，不报错 */
GPIO_WriteBit(GPIOA, GPIO_Pin_0, Bit_RESET);     /* 又操作 GPIOA */
```

### 5. 运算符优先级
`if(Byte & (0x01<<i) != 0)` → `!=` 优先 → 等于 `Byte & 1`。必须 `if((Byte & (0x01<<i)) != 0)`

### 6. armcc 对隐式声明只警告一次
4 处 `OLED_DrawStrintg` 拼错，编译器只报第 1 处 `#223`，链接时才报 1 条 `L6218E` —— **别以为只有一处错**

### 7. OLED 相关易错
- `OLED_SetBrush` 只有 2 参（画笔才 3 参）
- `BRUSH_WHITE` 没有 `COLOR`
- 字体变量是小写 `h`
- `default_font` 字宽约 6~7px → 128px 屏幕**一行最多约 21 字符**，超了自动折行

### 8. W25Q64（SPI Flash）
- `buffer[10]=0x06` 越界（数组只有 0~9）→ 写使能从未发出
- 扇区擦除 `0x20` 后**必须跟 3 字节地址**（共 4 字节）
- 擦除后写使能会被自动清除，**页编程前必须再发一次 `0x06`**
- 读状态寄存器：发 `0x05` 再发 `0xFF` 提供时钟，状态在**第 2 个返回字节**
- 空白片读出 `0xFF`，不是 `0x00`
- `WP#` / `HOLD#` 必须接 3.3V，否则芯片不工作
- 模块上的 LED 是**电源指示灯**，只反映 VCC/GND

### 9. JTAG 引脚
PB3/PB4/PA15 默认是 JTAG → 当普通 IO 用必须先
`GPIO_PinRemapConfig(GPIO_Remap_SWJ_JTAGDisable, ENABLE);`
**但绝不能碰 PA13/PA14（SWDIO/SWCLK）**，否则再也烧不进程序（需按住 RST 才能救）

### 10. 中断/复位相关
- `GPIO_Init` 不改 ODR，ODR 复位值 0 → **PC13 配成输出瞬间会先亮一下**
- Keil 默认不勾 `Reset and Run` → 下载后要**手动按 RST 键**

### 11. MicroLIB 与优化
- `useUlib=1` → ~~printf 不支持 `%f`~~ **实测（2026 年 MultiConv 双通道 ADC）：`My_USART_Printf` 里的 `%.3f` 正常输出，能画出曲线**。别再无谓地绕开浮点，先试再说
- `Optim=1`(-O1)：实测 `delay_us` 的空 for 循环**没被删**，但为保险应加 `volatile`
